Project Overview

Project Abstract

This project presents a software-based smart two-wheel autonomous robot capable of moving toward a target while avoiding obstacles. The system combines differential-drive kinematics, forward and inverse kinematics, homogeneous transformation, motion simulation, torque control and obstacle avoidance.

🤖 Robot Type

Two-wheel differential-drive mobile robot.

🧠 Main Intelligence

Target tracking and obstacle avoidance.

⚙️ Technologies

HTML, CSS, JavaScript, Canvas and Robotics Mathematics.

🎯 Main Goal

Reach the target safely without colliding with obstacles.

About the Project

Objectives

  • Design a two-wheel differential-drive robot simulation.
  • Implement obstacle avoidance logic.
  • Demonstrate forward and inverse kinematics.
  • Calculate robot position using transformation matrices.
  • Demonstrate linear and rotational motion.
  • Build a colorful interactive user interface.

System Modules

Robot Simulation Obstacle Avoidance Forward Kinematics Inverse Kinematics Transformation Matrix Torque Control Motion Control Interactive Dashboard

Future Enhancements

  • Connect the system with a real Arduino robot.
  • Add ultrasonic and LiDAR sensor data.
  • Use ROS2 and Gazebo for realistic simulation.
  • Add camera-based obstacle detection.
  • Implement PID motor control.
  • Add machine learning for path planning.
